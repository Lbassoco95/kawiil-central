# Célula PROC — Procesos internos

**Ámbito:** procesos internos (digitalización, diseño y documentación de procesos).

## Preguntas mínimas (ruta estándar, Capa 5b)

1. ¿Se busca **digitalizar** un proceso existente o **diseñar uno nuevo**?
2. ¿Qué **personas o áreas** están involucradas?
3. ¿Hay una **fecha o proyecto** asociado?
4. ¿El proceso está **documentado** actualmente?

> Estas preguntas se cargan en `switchboard_config.preguntas` para la célula PROC.

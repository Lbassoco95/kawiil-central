# Célula LIT — Litigio

**Ámbito:** litigio, audiencias, amparos, detenciones.

## Preguntas mínimas (ruta estándar, Capa 5b)

1. ¿Hay una **audiencia o fecha límite** próxima? ¿Cuándo?
2. ¿Hay una **persona detenida** o bajo custodia?
3. ¿Existe un **documento de autoridad** (citatorio, oficio, notificación)?
4. ¿Ante qué **juzgado o instancia** se lleva el asunto?
5. ¿Cuentan con **número de expediente**?

> Estas preguntas se cargan en `switchboard_config.preguntas` para la célula LIT.
> Señales de urgencia relevantes: audiencia < 48h, persona detenida, requerimiento
> de autoridad (ver `sw-urgency`).

# Célula COMP — Compliance (PLD-FT)

**Ámbito:** PLD-FT, KYC, regulación, auditorías.

## Preguntas mínimas (ruta estándar, Capa 5b)

1. ¿Recibieron una **notificación de autoridad regulatoria**?
2. ¿Hay una **fecha límite de respuesta**?
3. ¿El tema es de **PLD-FT, protección de datos o auditoría**?
4. ¿Es un asunto **preventivo** o ya **en curso**?

> Estas preguntas se cargan en `switchboard_config.preguntas` para la célula COMP.
